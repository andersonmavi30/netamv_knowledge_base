# Interpreter and Python runtime

[🇬🇧 English](01-interpreter.md) · [🇨🇴 Español](01-interpreter.es.md) · [↩ Python](README.md)

**Platform:** Python 3.10+; Linux/macOS. Windows can use `py --version`.

## `python3 --version`

```bash
python3 --version
```

- **Purpose:** Check the installed interpreter version before running network automation scripts.
- **Arguments:** `--version`: print version; `python3`: Python executable on Linux/macOS.
- **Use case:** Verify Python 3 is available before installing Netmiko or Requests.
- **Official reference:** https://docs.python.org/3/using/cmdline.html
