# Intérprete y ejecución de Python

[🇬🇧 English](01-interpreter.md) · [🇨🇴 Español](01-interpreter.es.md) · [↩ Python](README.es.md)

**Plataforma:** Python 3.10+; Linux/macOS. Para Windows puede usarse `py --version`.

## `python3 --version`

```bash
python3 --version
```

- **Sirve para:** Comprobar la versión del intérprete antes de ejecutar scripts de automatización de redes.
- **Parámetros:** `--version`: muestra la versión; `python3`: ejecutable del intérprete en Linux/macOS.
- **Ejemplo de uso:** Confirmar que el laboratorio usa Python 3 antes de instalar Netmiko o Requests.
- **Referencia oficial:** https://docs.python.org/3/using/cmdline.html
