**NX / N / X:** Dell no tiene una CLI universal para estos nombres de familia. N y X son series de hardware; los equipos X pueden usar interfaces web o CLI limitada. Confirma el modelo exacto y OS con `show version` cuando exista ese comando.

**Captura:** no se documenta un comando sniffer universal para los tres OS. Los contadores, logs y port mirroring son el punto de partida; valida si existe captura nativa según equipo y versión.
